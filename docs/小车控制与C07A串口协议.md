# 小车控制与 C07A 串口协议

## 1. 边界与数据流

小车控制是 Nano 本机功能，不经过 NX、ROS Master 或 TCP 8001：

```text
LandScreen 小车控制页
  -> Nano USB 串口 115200 8N1
C07A / MSPM0G3507
  -> S27F 的 TB6612、编码器和 MPU6050
```

任务地图仍通过 TCP 8001 与 NX 通信，两条链路相互独立。自动比赛模式会锁定
本页人工摇杆；人工摇杆仅用于架空调试和赛前检查。

## 2. 启动和串口选择

推荐先找出 C07A 的稳定设备路径：

```bash
ls -l /dev/serial/by-id/ /dev/ttyACM* 2>/dev/null
```

可以在“小车控制 -> 串口设置”中保存路径，也可以在启动时传入：

```bash
CAR_SERIAL_PORT=/dev/serial/by-id/<c07a-device> ./planescreen
```

未配置时默认尝试 `/dev/ttyACM0`。如果端口存在但无法打开，应检查当前用户是否
属于串口所属用户组；不要用长期 `sudo ./planescreen` 代替正确权限配置。

## 3. UI 安全状态机

电机启动必须同时满足：

1. 100 Hz 遥测和 10 Hz 电机状态均未超时。
2. IMU 校准达到 100%，C07A 报告 `SYSTEM_READY`。
3. 摇杆处于中心，模式为“手动调试”。
4. 持续按住启动按钮 2 秒，C07A 返回成功 ACK。

UI 以 20 Hz 发送左右轮命令。摇杆松手会立即发送零命令；急停会清空待发队列并
连续发送三次停车命令；返回地图、关闭控制页、切换自动模式和切换串口也会停车。
如果 USB 已物理断开，C07A 的 300 ms 看门狗负责最终停车并撤销使能。

首次上电的 UI 速度上限为 15%，只有在架空核对左右轮和正反方向后才逐步提高。
无论 UI 如何设置，固件硬限制均为 40%。

## 4. 帧格式

所有帧为：

```text
AA 55 | version:u8 | type:u8 | length:u8 | payload | crc16_le
```

- `version=1`。
- CRC16-CCITT-FALSE：初值 `0xFFFF`，多项式 `0x1021`。
- CRC 覆盖 `version/type/length/payload`，不覆盖帧头和 CRC 自身。
- 多字节数值均为小端。

### Nano 到 C07A

| type | payload | 说明 |
| --- | --- | --- |
| `0x80` | `nonce:u16` | PING。 |
| `0x82` | `seq:u16, guard:u16=0xA55A` | 请求使能。 |
| `0x83` | `seq:u16, left:i16, right:i16` | 左右轮有符号千分比。 |
| `0x84` | `seq:u16, reason:u8` | 立即停车并撤销使能。 |

使能后 `0x83` 必须使用递增序号持续刷新。重复、陈旧、CRC 错误或长度错误的命令
不会更新看门狗。

### C07A 到 Nano

| type | payload | 频率/说明 |
| --- | --- | --- |
| `0x01` | 31 字节 IMU/编码器状态 | 100 Hz。 |
| `0x02` | 16 字节电机状态 | 10 Hz。 |
| `0x81` | `nonce:u16` | PING_ACK。 |
| `0x90` | `command_type:u8, seq:u16, result:u8` | 命令 ACK。 |

`0x02` payload：

```text
status_bits:u16
last_command_sequence:u16
target_left:i16, target_right:i16
applied_left:i16, applied_right:i16
watchdog_remaining_ms:u16
stop_reason:u8
max_command_percent:u8
```

## 5. 不接电机的模拟验证

Linux 上可以用伪终端模拟 C07A：

```bash
cd LandScreen-master
python3 tools/fake_car_controller.py --link /tmp/c07a-sim
```

另一个终端运行：

```bash
cd LandScreen-master/build
CAR_SERIAL_PORT=/tmp/c07a-sim ./planescreen
```

模拟器会在 1 秒后完成校准，支持使能、限幅、递增序号、ACK、编码器变化和
300 ms 看门狗。协议单元测试：

```bash
python3 LandScreen-master/tools/test_car_protocol.py
```

## 6. 实车验收顺序

1. 不接 12 V 电机电源，验证遥测、控制状态、长按使能 ACK 和急停 ACK。
2. 车轮完全架空，15% 上限，分别核对左轮、右轮及前后方向。
3. 测试摇杆松手、急停、返回地图、拔 USB，确认 300 ms 内 PWM 归零。
4. 才允许落地低速测试；如左右轮定义或正方向不符，应改固件方向配置并重新完成
   第 2、3 步，不能只在 UI 文案中交换左右。

轮径已知为 65 mm，但编码器每轮脉冲数和安装方向尚未完成实测标定，因此 UI 当前
显示编码器累计计数，不伪造 m/s。完成每轮计数标定后再增加线速度和里程换算。
